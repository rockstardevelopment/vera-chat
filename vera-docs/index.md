# vera-docs

Fork-owned documentation for
[rockstardevelopment/vera-chat](https://github.com/rockstardevelopment/vera-chat), a fork of
[danny-avila/LibreChat](https://github.com/danny-avila/LibreChat). It covers what this fork does
differently from upstream.

## How this tree is organized

Every directory under `vera-docs/` contains an `index.md`:

- The `index.md` of a directory explains that layer: describes direct children with a one-line summary each.
- It links to the parent `index.md`, so navigation works in both directions.
- Reading only the `index.md` files from this root down describes the whole tree. 

When you add, rename, or remove a page, update the `index.md` of the directory that holds it. When
you create a directory, give it an `index.md` before adding pages.

## What belongs here

- Fork-specific process: branching beyond the upstream policy, release flow, review conventions.
- Deployment and operations: environments, droplets, secrets, rollback, runbooks.
- Environment and configuration knowledge that differs from upstream defaults.

## What does not

- Application, API, or user documentation - that belongs with upstream docs.
- Instructions already owned by upstream (`CLAUDE.md`, `AGENTS.md`) or generated by tooling
  (`openspec/` artifacts, `.opencode/` skills).
- One-off notes: keep them in the change or issue they belong to.

## Keeping this current

Documentation is part of done. A change that alters fork-specific process, deployment, or operator
workflow updates the affected page and the `index.md` files on its path in the same change.
## Pages

| Page | Covers |
| --- | --- |
| [`deployment.md`](./deployment.md) | Manual GitHub Actions deployment of the API image to the development and production droplets: prerequisites, secrets, dispatch, rollback. |
| [`fork-workflow.md`](./fork-workflow.md) | The fork's remotes, branch roles, upstream sync, and the fast-forward-only `main` invariant. |

A future layer gets its own subdirectory and `index.md`, for example:

```text
vera-docs/
├── index.md
├── deployment.md
├── fork-workflow.md
└── operations/
    ├── index.md
    └── <page>.md
```
